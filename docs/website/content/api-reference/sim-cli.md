This section gives the details API reference for the `fedgwas-sim` CLI used for local federated GWAS simulation. 

# Local Simulation CLI Reference

## Initialization

### Initialization: `fedgwas-sim init`

### Experiment Setup: `fedgwas-sim setup-experiment <preset>`

### Data Preparation: `fedgwas-sim prepare-data`

## Summarization And Checks

### Summarize Data: `fedgwas-sim summarize data`

### Summarize Experiment: `fedgwas-sim summarize experiment`

### Readiness Checks: `fedgwas-sim check`

## Running Simulations and Evaluating Results

### Run Simulation: `fedgwas-sim run`

### Baseline Generation: `fedgwas-sim baseline generate`

### Evaluation: `fedgwas-sim evaluate`

### Results Collection: `fedgwas-sim results collect`
